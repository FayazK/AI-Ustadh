# Authentic Sources — quran-deep-research

A prioritized source list for the seven-layer Urdu deep-research document. Use these as the
first resort for every layer. If a source is unavailable or paywalled, note the gap rather
than substituting an unverified one.

---

## 1. Quranic Arabic Text (mandatory exact source)

- **quran.com** — `https://quran.com/<surah>/<ayah>` — canonical Arabic, multiple translations.
- **corpus.quran.com** — `https://corpus.quran.com/wordbyword.jsp?chapter=<n>&verse=<n>` —
  word-by-word morphology, root, dependency parse.
- **King Fahd Complex (qurancomplex.gov.sa)** — Madinah Mushaf official PDF for orthography.
- **tanzil.net** — clean, standard text in multiple scripts.

**Rule:** Arabic Ayah text must be copied verbatim from one of these. No paraphrase, no
re-typing from memory.

without flagging it.

## 9. Scientific / Empirical Sources (for Layer 7.1 — handle with caution)

- Peer-reviewed journals (Nature, Science, PubMed) for any empirical claim
- Zaghloul El-Naggar — scientific tafsir (cite, but distinguish his interpretive layer from
  hard science)
- *The Bible, The Qur'an and Science* — Maurice Bucaille (older, treat as historical
  reference, not authority)

**Hard rule:** Never write "science has proven this Ayah" beyond what peer-reviewed evidence
actually supports. If the connection is interpretive, mark it as such in Urdu (مفسرین کا
استنباط، نہ کہ ثابت شدہ سائنسی حقیقت).

## 10. Source-Citation Format (used in Layer 8 of the document)

```
- Tafsir Ibn Kathir — Surah al-Baqarah ayah 255 — tafsir.app/ibn-kathir/2/255
- Sahih al-Bukhari 4474 — sunnah.com/bukhari:4474 — صحیح
- Lane's Lexicon — root ر-ح-م — p. 1056
- Nouman Ali Khan — "Surah al-Fatiha Analysis" — youtube.com/watch?v=… — 00:14:32
- Mufti Shafi Usmani — Maariful Quran vol. 1, p. 96 — section: شانِ نزول
```

Always include: source name, author/scholar, exact location (page / hadith number /
timestamp), and URL where available.
