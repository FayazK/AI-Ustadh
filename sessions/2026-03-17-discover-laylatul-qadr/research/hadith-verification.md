# Hadith Verification — Laylatul Qadr

## Sahih al-Bukhari — Book 32: Virtues of the Night of Qadr

| # | Hadith | Narrator | Grading | Link |
|---|--------|----------|---------|------|
| 1 | صحیح بخاری 2014 | ابوہریرہ | صحیح | [sunnah.com/bukhari:2014](https://sunnah.com/bukhari:2014) |
| | جو رمضان میں ایمان اور ثواب کی نیت سے روزے رکھے اس کے پچھلے گناہ معاف۔ جو شبِ قدر میں ایمان اور ثواب کی نیت سے قیام کرے اس کے پچھلے گناہ معاف۔ |
| 2 | صحیح بخاری 2015 | ابن عمر | صحیح | [sunnah.com/bukhari:2015](https://sunnah.com/bukhari:2015) |
| | صحابہ نے شبِ قدر خواب میں آخری سات راتوں میں دیکھی۔ نبی ﷺ نے فرمایا: آخری سات راتوں میں تلاش کرو۔ |
| 3 | صحیح بخاری 2016 | ابوسعید خدری | صحیح | [sunnah.com/bukhari:2016](https://sunnah.com/bukhari:2016) |
| | نبی ﷺ کو شبِ قدر دکھائی گئی پھر بھلا دی گئی۔ فرمایا: مٹی اور پانی میں سجدہ کرتا دیکھا۔ اکیسویں رات بارش ہوئی اور نبی ﷺ مٹی اور پانی میں سجدہ کرتے نظر آئے۔ |
| 4 | صحیح بخاری 2017 | عائشہ | صحیح | [sunnah.com/bukhari:2017](https://sunnah.com/bukhari:2017) |
| | شبِ قدر رمضان کی آخری دس طاق راتوں میں تلاش کرو۔ |
| 5 | صحیح بخاری 2018 | ابوسعید خدری | صحیح | [sunnah.com/bukhari:2018](https://sunnah.com/bukhari:2018) |
| | نبی ﷺ نے پہلے درمیانی عشرے میں اعتکاف کیا، پھر آخری عشرے میں منتقل ہوئے اور فرمایا: آخری دس طاق راتوں میں تلاش کرو۔ |
| 6 | صحیح بخاری 2020 | عائشہ | صحیح | [sunnah.com/bukhari:2020](https://sunnah.com/bukhari:2020) |
| | نبی ﷺ رمضان کے آخری عشرے میں اعتکاف فرماتے اور فرماتے: شبِ قدر آخری دس راتوں میں تلاش کرو۔ |
| 7 | صحیح بخاری 2021 | ابن عباس | صحیح | [sunnah.com/bukhari:2021](https://sunnah.com/bukhari:2021) |
| | شبِ قدر آخری عشرے کی طاق راتوں میں تلاش کرو — جب نو باقی ہوں، سات باقی ہوں، پانچ باقی ہوں (اکیسویں، تئیسویں، پچیسویں)۔ |
| 8 | صحیح بخاری 2023 | عبادہ بن صامت | صحیح | [sunnah.com/bukhari:2023](https://sunnah.com/bukhari:2023) |
| | نبی ﷺ شبِ قدر کی تاریخ بتانے آئے لیکن دو مسلمانوں کا جھگڑا ہوا تو علم اٹھا لیا گیا۔ فرمایا: انتیسویں، ستائیسویں، پچیسویں میں تلاش کرو۔ |
| 9 | صحیح بخاری 2024 | عائشہ | صحیح | [sunnah.com/bukhari:2024](https://sunnah.com/bukhari:2024) |
| | آخری عشرہ شروع ہوتا تو نبی ﷺ کمر کس لیتے، رات بھر جاگتے، اور گھر والوں کو بھی جگاتے۔ |
