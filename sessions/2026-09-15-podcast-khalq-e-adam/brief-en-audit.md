Method: every ayah fetched from the alquran.cloud API (Sahih International + Arabic checked); every sunnah.com number fetched with a browser user agent (text, narrator, displayed grade, and al-Tirmidhi's own Arabic grade read); off-sunnah.com grades checked on dorar.net (grader entries); al-Bidaya wa al-Nihaya and Tarikh al-Tabari pages read on shamela.ws (al-Turki / Dar al-Turath pagination, URL page = printed page in vol. 1 from ~p. 262; URL page + 1 = printed page before that); modern quotations checked against the library transcripts, masud.co.uk (Keller), theo-puzzles.ac.uk (Malik), the Jalajel PDF (pdftotext), islamicstudies.info (Maududi), islamqa.info, yaqeeninstitute.org (Brown); science citations resolved through the CrossRef API, NCBI E-utilities abstracts, nature.com, essd.copernicus.org, unesco.org; YouTube IDs resolved through the oEmbed endpoint.
